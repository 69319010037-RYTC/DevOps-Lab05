# เกมต่อภาพรถยนต์

เกม Jigsaw Puzzle บนเว็บ ใช้ HTML, CSS และ JavaScript แบ่งภาพ `car.jpg` เป็น 20 ชิ้นแบบมีขอบนูนและเว้าที่ประกบกัน กระดานแสดงเฉพาะรอยต่อบนพื้นสีฟ้าพาสเทล มีเพลงพื้นหลังและเสียงเอฟเฟกต์เมื่อต่อชิ้นส่วนถูกต้อง

## วิธีเล่น

เปิดโปรเจกต์ผ่านเว็บเซิร์ฟเวอร์ในเครื่อง เช่น VS Code Live Server แล้วเล่นในเว็บเบราว์เซอร์ ลากชิ้นส่วนไปยังตำแหน่งที่ตรงกัน หรือเลือกชิ้นส่วนแล้วเลือกช่องบนกระดาน เมื่อต่อครบทุกชิ้นจะแสดงข้อความว่าชนะ

กดปุ่ม **เริ่มใหม่** เพื่อสุ่มตำแหน่งชิ้นส่วนและเริ่มเล่นอีกครั้ง

กดปุ่ม **เปิดเพลง** เพื่อเล่นหรือหยุดเพลงพื้นหลังจากไฟล์ `background-music.mp3` (เบราว์เซอร์บางตัวอาจไม่อนุญาตให้เล่นไฟล์เสียงเมื่อเปิดหน้าเว็บด้วย `file://`)
